## 五、⚠️ 容易写错的地方

### 1. 测试数据必须与后端演示数据对齐

后端 `apps/common/demo.py` 定义了标准数据集（`v0.19.0`/`v1.0.0`）：
`cs_manager` 看 50 条、`cs_staff` 看 5 条……

前端 fixtures **必须用同一套数字**：

```ts
// src/test/fixtures.ts
export const CS_MANAGER_PROFILE = {
  user: { username: 'cs_manager', ... },
  perms: ['ticket:ticket:view', 'ticket:ticket:create', ...],   // 与后端一致
  menus: [...],
}
```

不一致的话，前端测试全绿但一接真后端就崩——**测的不是同一个系统**。

### 2. MSW 拦的是网络层，不是 axios

```ts
// ❌ mock axios：测不到拦截器
vi.mock('axios')

// ✅ MSW：拦截真实的 fetch/XHR，拦截器照常执行
server.use(http.get('/api/v1/auth/profile/', () => HttpResponse.json(...)))
```

我们的权限逻辑有**一半在拦截器里**（CSRF 注入、401 分流、版本号比对）。
mock 掉 axios 就把它们全跳过了。

### 🔴 3. 前后端权限码对账（第一节第 3 问）

后端 `v0.10.0` 的结构性测试：

```python
def test_every_template_guard_has_a_view_guard(self):
    """模板里有几个 `in perms`，视图层就该有几个对应的 @require_perm。"""
```

前端版要对账两件事：

```ts
// 1. 前端用到的权限码，后端都存在
//    （TS 类型已经保证了——但常量文件可能过期，所以还要跑一次）
// 2. 前端用到的权限码，后端 perm_map 里有对应声明
//    （即「隐藏了按钮但后端没拦」）
```

实现：扫描 `src/**/*.tsx` 里的 `PERM.XXX` 引用，
与 `src/constants/permissions.ts` 和后端导出的清单比对。

⚠️ **第 2 条前端做不完整**——它需要知道后端的 `perm_map`，
那要么后端再导出一份，要么留给 E2E。**本 tag 先做第 1 条，第 2 条记在 TODO。**

诚实地承认这个缺口，比假装覆盖了要好。

### 4. `staleTime: Infinity` 让测试之间串数据

QueryClient 是模块级单例的话，测试 A 拉的 profile 会被测试 B 读到。

```ts
// 每个测试新建一个 QueryClient
function renderWithProviders(ui: ReactElement) {
  const client = new QueryClient({ defaultOptions: { queries: { retry: false } } })
  return render(<QueryClientProvider client={client}>{ui}</QueryClientProvider>)
}
```

对照后端 `v0.16.0` 加的 `tests/conftest.py` 全局清缓存 fixture——
**同一个问题的两种语言版本**：有缓存就必须管测试隔离。

### 5. 权限相关的模块要求 90% 覆盖率

```
src/auth/**          ≥ 90%
src/components/Can   ≥ 90%
src/router/**        ≥ 90%
整体                 ≥ 80%
```

和后端 `apps/rbac ≥ 90%` 是同一个标准。

### 6. 有些东西单测测不了，别硬测

第一节第 4 问：

| 测不了的 | 为什么 | 留给谁 |
| --- | --- | --- |
| `document.cookie` 里没有 sessionid | jsdom 不实现 httpOnly | E2E |
| 绕过前端直接调 API 被拒 | 需要真后端 | E2E |
| 真实的 CSRF 校验 | 同上 | E2E |
| 动态路由在真实浏览器刷新后的行为 | jsdom 的 history 行为有差异 | E2E |

**硬用 jsdom 测这些，会写出「测了但没测到」的假测试**——比不测更糟。
